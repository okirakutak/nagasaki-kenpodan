# 無料で公開できる代表的なホスティングサービス

GASの警告バナーを回避しつつ、今回のようなReact（Vite）で作ったフロントエンド画面（`index2.html`等）を無料で公開できる代表的なホスティングサービスを5つご紹介します。

どれも**無料枠（Free Tier）が非常に充実しており、個人開発や小規模なビジネス利用なら無料で十分運用できる**のが特徴です。

------

### 1. Vercel（ヴェルセル）

現在のフロントエンド開発において、最も人気があり勢いのあるサービスの一つです。

- **特徴**: Reactの開発元とも関わりが深く、Next.jsという有名なフレームワークの提供元でもあります。Viteで作ったアプリも驚くほど簡単にデプロイできます。
- **メリット**:
  - **圧倒的な設定の簡単さ**: GitHubと連携するだけで、コードを更新（プッシュ）するたびに自動でビルド＆公開してくれます。
  - **表示速度が速い**: 世界中にサーバー（CDN）があり、どこからアクセスしても高速に表示されます。
  - **プレビュー機能**: 更新ごとに「テスト用の仮URL」を発行してくれるため、本番公開前に確認がしやすいです。
- **デメリット**:
  - 無料枠での「商用利用（直接的な利益を生むサイト）」は規約上グレーまたはNGとされています（※自社のパンフレットサイトやシミュレーター程度なら問題ないことが多いですが、大規模な広告収入や直接販売などには有料プランへの移行が推奨されます）。

### 2. Netlify（ネットリファイ）

Vercelの最大のライバルであり、古くから人気のある静的サイトホスティングサービスです。

- **特徴**: 「とにかく設定不要で動かせる」ことにこだわったプラットフォームです。
- **メリット**:
  - **ドラッグ＆ドロップで公開可能**: GitHubなどのGitを使えなくても、ビルドしたフォルダ（今回の `app/dist/` など）をブラウザ画面にドラッグ＆ドロップするだけで即座に公開できます。
  - **無料枠で商用利用が可能**: Vercelと異なり、無料枠での商用利用が明確に許可されています。
  - **フォーム機能が無料**: お問い合わせフォームなどをHTMLだけで簡単に作れる機能が無料でついています。
- **デメリット**:
  - アクセス数が爆発的に増えた場合の無料枠の上限がVercelやCloudflareに比べると少し厳しめです（ただし月間100GBまでは無料なので、通常はまず超えません）。

### 3. Cloudflare Pages（クラウドフレア ページス）

セキュリティと通信速度の世界的企業であるCloudflareが提供するサービスです。

- **特徴**: とにかく無料で使える上限がダントツで太っ腹です。
- **メリット**:
  - **帯域幅（通信量）が無制限**: 他のサービスが「月間100GBまで」としている中、なんと通信量が完全に無制限です。
  - **爆速**: Cloudflareの強力なCDNネットワークを利用するため、表示速度は最高クラスです。
  - **無料枠での商用利用OK**。
- **デメリット**:
  - 最初の設定画面が他の2つに比べるとほんの少しだけ専門的（直感的でない）かもしれませんが、一度設定すれば全自動です。

### 4. GitHub Pages（ギットハブ ページス）

ソースコード管理サービス「GitHub」の標準機能として提供されているホスティングです。

- **特徴**: エンジニアのインフラとして最も定着しているホスティングの一つです。
- **メリット**:
  - 完全無料で、商用利用も制限はありません。
  - GitHubでソースコードを管理しているなら、そのまま設定一つで公開できます。
- **デメリット**:
  - 自分で「ビルドして公開用のブランチに送る」という仕組み（GitHub Actionsなど）を少し設定する必要があり、VercelやNetlifyほどの「全自動で楽々」感はありません。
  - URLが `https://ユーザー名.github.io/リポジトリ名/` となり少し長くなります（独自ドメインも設定可能です）。

### 5. Firebase Hosting（ファイアベース ホスティング）

Googleが提供している開発プラットフォーム「Firebase」の一部です。

- **特徴**: GASと同じGoogleのサービスなので、相性が良いです。
- **メリット**:
  - Googleの強力なインフラに乗っているため非常に安定しています。
  - 将来的にデータベース機能やログイン認証機能を追加したくなったとき、Firebaseの他機能とスムーズに連携できます。
- **デメリット**:
  - 公開するためにターミナル（黒い画面）でコマンド（`firebase deploy`）を叩く必要があり、ドラッグ＆ドロップで終わるNetlifyなどに比べると初回の学習コストが少し高いです。

------

### おすすめの選び方

今回の「協会けんぽシミュレーター」のようなアプリを公開する場合、以下の基準で選ぶのがおすすめです。

1. **一番手軽で、商用利用も安心して行いたい場合** 👉 **Netlify** がおすすめです。（画面にフォルダをドラッグ＆ドロップするだけでも公開できるので一番簡単です）
2. **将来のアクセス増にも耐えられる最強の通信インフラを使いたい場合** 👉 **Cloudflare Pages** がおすすめです。
3. **とにかくモダンでカッコよく、GitHubと連携して全自動化したい場合** 👉 **Vercel** がおすすめです。（商用利用の規約だけ注意）
