# 長崎ケンポー団

**データに基づく健康経営・社会保険料削減プロジェクト**

長崎データ塾2026 の実証プロジェクト「長崎県民の手取りを増やす」における、長崎ケンポー団の成果物リポジトリです。
高い社会保険料という長崎県の課題に、データ分析と Web 展示で立ち向かうことを目的としています。

---

## プロジェクト概要

- **課題**: 長崎県の健康保険料率（10.45%）は全国ワースト圏であり、県民・企業の手取りを圧迫している
- **アプローチ**: 協会けんぽのインセンティブ5指標と保険料率の関係をデータ分析し、健康行動による保険料削減効果を可視化する
- **成果物**:
  1. データ分析（相関分析・重回帰分析）
  2. 保険料削減シミュレーター
  3. 企業・県民向けランディングページ（本リポジトリの Web サイト）

## 保険料削減シミュレーター

`simulator.html` に単一ファイルで実装された、令和8年度 協会けんぽ向けシミュレーターです。

### 入力項目

- 従業員数
- 平均年収（万円）
- 現在の特定健診受診率（%）
- 目標の特定健診受診率（%）

### 計算ロジック（`js/app.js` より）

- 特定健診受診率が **10%向上** → 保険料率が **-0.11%** 低下（データ分析モデルに基づく）
- 長崎県基準の保険料率: 10.45%（下限 9.0%）
- 会社負担の社会保険料削減額（年間）= 総給与額 ×（率低下分 ÷ 2）※効使折半
- 生産性効果 = 従業員数 ×（受診率改善に応じた 1人あたり 20万円スケール）

### 出力

- 保険料率の変化（現在 → シミュレーション後）
- 年間の会社負担削減額
- 生産性・総生産向上額
- 変更前後の会社負担額比較チャート（Chart.js）

## データ分析の要点（docs/ 参照）

詳細は `docs/` 配下の資料を参照してください。

### 1. 5つのインセンティブ指標と保険料率の相関分析

47都道府県 × 5年分（235件）のデータによる相関係数:

| 指標 | 相関係数 | 読み |
|------|---------|------|
| 特定健診等実施率 | **-0.299** | 最も強い負の相関 |
| 後発医薬品使用割合 | **-0.260** | 2番目に強い負の相関 |
| 受診勧奨率 | -0.130 | 弱い負の相関 |
| 特定保健指導実施率 | -0.031 | ほぼ相関なし |
| 対象者減少率 | +0.077 | ごくわずかな正の相関 |

**示唆**: 「特定健診の受診率」と「ジェネリック医薬品の使用割合」を上げることが、保険料率引き下げの最も有力な要因。

### 2. 保険料率の構成要素分析

最終保険料率は以下の要素の**足し算・引き算**で決定されることを確認（決定係数 **0.997**）:

```
予測保険料率 = 調整前所要保険料率
             + 年齢調整
             + 所得調整
             + 一律加算保険料率
             + 精算分
             + インセンティブ分
```

→ インセンティブ分の改善が、そのまま最終保険料率の引き下げに直結する。

## 動かし方

静的サイトのため、ビルドは不要です。

### 方法1: ブラウザで直接開く

```bash
open index.html
# Linux の場合
xdg-open index.html
```

### 方法2: ローカルサーバーで起動（推奨）

```bash
# Python の場合
python3 -m http.server 8000

# Node.js の場合
npx serve .
```

ブラウザで `http://localhost:8000` を開いてください。

### 必要な外部リソース（CDN）

以下のライブラリは CDN から読み込むため、インターネット接続が必要です。

- [Google Fonts](https://fonts.google.com/) — Noto Sans JP / Plus Jakarta Sans
- [Chart.js](https://www.chartjs.org/) — グラフ描画
- [Lucide Icons](https://lucide.dev/) — アイコン
